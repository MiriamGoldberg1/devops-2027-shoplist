אנלוגיה של קונדיטיריה
רכיב                   	איפה הוא רץ (הנהלה / כל node)	                    מה הוא עושה,  במשפט אחד                                    	אנלוגיה
API server			         control plane                                      מקבל בקשות cluster דלפק ראשי                     הוא נקודת הכניסה ל
etcd			                control plane                                  פנקס ההזמנות של החנות                   שומר את כל הנתונים של הקלסטר                           
scheduler			           control plane                               מחליט באיזה מטבח תאפה כל עוגה- לפי העומס         מחליט על איזה צומת ירוץ כל פוד  חדש,                                         
controller manager			control plane          בודק כל הזמן אם יש מספיק עוגות, ואם חסרה עוגה, מזמין חדשה.           משווה כל הזמן בין המצב הרצוי למצב הקיים, ופועל לסגור את הפער.
kubelet			             כל node           הקונדיטור הראשי בכל מטבח               מקבל את הפודים שהוקצו לו, דואג שירוצו ומדווח על מצבם להנהלה 
container runtime			כל node         מריץ בפועל את ה-containers לפי ה-image                                      תנור שאופה את העוגה
kube-proxy			כל node                             מחליט בכל מטבח איזה טבח יאפה כל עוגה    מנתב תעבורה שמגיעה ל-Service אל אחד ה-pods שמאחוריו.
